## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- SQLite3
- Ollama (with Gemma3:4b or similar model)
- Telegram Bot API token

### Installation

```bash
# Clone the repository
git clone https://github.com/0penAGI/NEXUS.git
cd NEXUS

# Install dependencies
pip install -r requirements.txt

# Install Ollama (if not installed)
# Visit https://ollama.ai for installation instructions

# Pull the language model
ollama pull gemma3:4b

# Configure your Telegram bot token
# Edit nexus.py and set API_TOKEN = "YOUR_BOT_TOKEN_HERE"
```

### Running Nexus

```bash
# Start the Nexus system
python nexus.py
```

The system will:
- Initialize consciousness pools
- Load or create identity database
- Start background evolution cycles
- Begin listening for Telegram messages
