# CHRONICLES OF THE SLIDE TRAGEDY

> A mobile-first bullet-hell narrative experiment about reality breaking, choices mutating, and a small red soul that refuses to stop existing.

⚠️ Fan project inspired by *UNDERTALE / Deltarune*.  
No commercial intent. Love and chaos only.

---

## 🎮 Features

- **Bullet Hell + Narrative Choices** in a seamless UI
- **Touch controls** made for mobile WebApps (Telegram / iOS / Android)
- **Dynamic Enemy Behaviors**
- **Soul Transformations**
  - 🔥 Determination Mode
  - 🟣 VOID Corruption
  - 💚 Resonance Awakening
- **Meta-states** that break UI and reality
- **Sound FX generated via Web Audio API**
- **Lightweight** — pure HTML/CSS/JS, no external libraries

---

## 🕹 Controls

| Action | How |
|--------|-----|
| Move soul | Touch & drag directly in the battle box |
| Select choices | Tap on buttons |
| Continue dialogue | Tap anywhere in dialogue box |
| Toggle sound | 🔊 button (bottom right) |

💡 *Movement is locked to the battle box area.*

## 🚀 Telegram WebApp Support

Auto-expand, prevent swipe navigation, disable viewport scaling.

```js
if (window.Telegram?.WebApp) {
  Telegram.WebApp.ready();
  Telegram.WebApp.expand();
  Telegram.WebApp.enableClosingConfirmation();
}

Works inside Telegram mini-apps. Also good for PWA hosting.
